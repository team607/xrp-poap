Step one

Prove the wallet.

Xaman will ask you to sign in. It is not a transaction — no fee, nothing submitted, nothing moved. It only proves the wallet is yours, which is the whole point: a badge is soulbound, so one minted to a mistyped address can never be moved and never be recovered.
