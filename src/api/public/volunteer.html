No seed, secret or private key is ever requested by, displayed in, or stored by this page. The issuer key lives server-side and is absent from responses, logs and errors by design. The attendee signs in their own wallet; this desk only ever sees their public address.

Camera frames never leave this tab. Decoding happens locally through the browser’s built-in BarcodeDetector; nothing is uploaded, nothing is recorded, and the track is stopped the instant a code is read or the tab is hidden.

Attendance is an event, not a state. A badge that is later burned still verifies, because the attendee’s NFTokenAcceptOffer hash is the attendance record.
