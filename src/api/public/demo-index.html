If you only have one screen

  1. Open volunteer here, and attendee in a second window side by side.
  2. The volunteer page takes a pasted address when there's no camera — scanning is optional.
  3. To use a real phone, restart with npm run demo -- --lan and open the address it prints. That puts the server on your local network, so only do it on a network you trust.
Testnet only. Every wallet on these pages is a throwaway funded from the XRPL testnet faucet, and the XRP is not money. No seed or private key is ever shown, requested or stored by any page here.
