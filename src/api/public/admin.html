New event

An event is a row in the database and a number on the ledger. Pick the number carefully: everything else here can be edited later.

1 Create POST /admin/api/events
Event id = NFTokenTaxon
— permanent

This integer is the NFTokenTaxon stamped into every badge minted for this event. It is written by NFTokenMint into the token itself and cannot be changed afterwards — not by editing this row, not by anything.

Do not reuse a number. Two events sharing a taxon become one on-chain collection: nfts_by_issuer?taxon=N returns both events’ badges mixed together, and verification cannot tell them apart. The server refuses a duplicate with a 409 for exactly this reason.

Any whole number from 0 to 2147483647. Pick one you can read out loud — it appears in the public URL and in every roster query.

The date of the event itself. The ledger never sees it.

Event-wide fallback badge artwork, used when per-attendee art is unavailable. Editable only until the first badge is minted — NFTokenMint.URI is written into the token and is immutable, so changing it later would leave minted badges pointing at the old artwork.
